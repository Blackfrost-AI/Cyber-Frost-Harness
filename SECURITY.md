# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability in the harness. Use
GitHub's private vulnerability reporting feature for this repository instead.
Include the affected version, a minimal reproduction, and the expected impact.

## Intended use

Cyber-Frost Harness is intended for authorized security research, controlled
evaluation, defensive validation, and work on systems you own or have explicit
permission to test. Its isolation controls are part of the design, not a
substitute for an organization's authorization and review process.

The repository intentionally excludes benchmark credentials, vulnerable and
fixed private images, proof-of-concept bytes, private task bundles, raw model
trajectories, and grader databases.
